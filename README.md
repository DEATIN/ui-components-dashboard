# Панель путешественника

Учебная практика 2: интерактивная панель управления UI-компонентами на HTML, CSS и обычном JavaScript. Классы виджетов разделены на ES-модули; установка пакетов и сборка не нужны.

[Открыть сайт](https://deatin.github.io/ui-components-dashboard/) · [Репозиторий](https://github.com/DEATIN/ui-components-dashboard)

## Запуск

Откройте терминал в папке проекта и запустите локальный HTTP-сервер:

```sh
python -m http.server 8000
```

Перейдите на `http://localhost:8000`. Для ES-модулей нужен HTTP-сервер: открытие `index.html` через `file://` не подходит. Для публикации в GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → / (root)**.

## Возможности

- Добавление трёх типов виджетов: задачи, погода и курс валют. Повторное добавление типа запрещено с понятной подсказкой.
- Сворачивание и удаление карточек; удаление сетевого виджета отменяет его запрос.
- Добавление, выполнение и удаление задач; пустые задачи не добавляются.
- Загрузка реальных данных, состояние ожидания, ошибки и повтор запроса отдельно для каждой карточки.
- Сохранение набора виджетов и задач в `localStorage`, восстановление после обновления. При запрете хранилища панель работает в текущей вкладке.
- Адаптивная сетка для компьютера и одна колонка для телефона.

## Источники данных

1. **[Open-Meteo](https://open-meteo.com/en/docs)** — текущая погода в Санкт-Петербурге: температура, ощущаемая температура, влажность, код погоды и скорость ветра. [Реальный запрос](https://api.open-meteo.com/v1/forecast?latitude=59.9386&longitude=30.3141&current=temperature_2m,relative_humidity_2m,apparent_temperature,weather_code,wind_speed_10m&timezone=Europe%2FMoscow&wind_speed_unit=ms); поля берутся из `current`.
2. **[Frankfurter](https://frankfurter.dev/)** — курс EUR к USD и дата курса. [Реальный запрос](https://api.frankfurter.dev/v2/rate/eur/usd); курс берётся из `rate`. Это справочный курс за указанную источником дату.

Оба API не требуют секретных ключей. При отказе сети панель показывает ошибку и кнопку повтора, а не подставляет вымышленные актуальные значения.

## Использование нейросети

Сайт создан с помощью **OpenAI Codex**. Полезные запросы, использованные при работе (сокращённо):

1. «Сделай полностью рабочую Практику 2: панель путешественника на HTML/CSS/обычном JavaScript с классами, ES-модулями, задачами, погодой и курсом валют» — каркас и отдельные классы виджетов.
2. «Проверь два реальных API, используй их фактические поля и обработай загрузку, ошибки, повтор и отмену запросов» — сетевые карточки.
3. «Проверь критерии задания: добавление, сворачивание, удаление, сохранение задач, повреждённый localStorage и пять циклов удаления/добавления» — проверка поведения и защита от отказов.

## Проверка перед сдачей

Добавьте все три виджета, попробуйте добавить повторный тип, сверните и удалите каждую карточку. Добавьте задачу, отметьте её выполненной, удалите другую и обновите страницу — задачи и набор виджетов должны восстановиться. Проверьте погоду и валюту через свою сеть; временно отключите интернет и убедитесь, что видны ошибка и повтор. Пять раз удалите и добавьте виджет: одно действие должно выполняться один раз. Проверьте страницу на телефоне и с клавиатуры.
